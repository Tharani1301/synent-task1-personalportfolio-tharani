Paper Presentation

Research Work

AI-Powered Adaptive Intrusion Detection System using Hybrid Deep Learning

Author: Tharani Natarajan | Department of AI & Data Science, IFET College of Engineering

Abstract

Modern network environments face sophisticated cyber threats that traditional signature-based intrusion detection systems struggle to capture. This paper proposes an adaptive intrusion detection architecture combining Random Forest classifiers for rapid anomaly feature extraction with Long Short-Term Memory (LSTM) recurrent neural networks for temporal sequence classification.

Problem Statement

Legacy firewalls fail against zero-day threats and multi-stage network intrusions due to high false-positive rates and lack of temporal pattern awareness.

Hybrid Methodology

Evaluated on the NSL-KDD dataset using a two-stage hybrid decision pipeline: static feature tree ranking followed by LSTM sequence memory evaluation.

Key Modules & Results

Real-time Network Monitoring Attack DNA Radar Visualization AI Cybersecurity Tutor Module Automated PDF Threat Audit Reports
