Paper Presentation

AI-Powered Adaptive Intrusion Detection System Using Hybrid Deep Learning

Author: Tharani Natarajan | Department of Artificial Intelligence & Data Science, IFET College of Engineering

Abstract

Modern network environments face sophisticated cyber threats that traditional signature-based intrusion detection systems struggle to capture. This paper presents an adaptive intrusion detection architecture combining Random Forest classifiers for feature selection and feature tree ranking with Long Short-Term Memory (LSTM) neural networks for temporal sequence classification.

Problem Statement

Legacy intrusion detection systems struggle with zero-day attacks and multi-stage network intrusions due to high false-positive rates and lack of temporal pattern awareness.

Methodology & Architecture

Evaluated on the NSL-KDD dataset using a hybrid decision engine: static feature selection using Random Forest followed by LSTM sequence memory evaluation.

Key Features & Results

Real-time Monitoring Attack DNA Radar AI Tutor Module Automated PDF Reporting
